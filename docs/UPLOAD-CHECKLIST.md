## ویدیوها — حداقل لازم

لازم نیست همه را بفرستید. **یک نمونه از هر سبک** کافی است:

- [ ] یک موشن از سبک اصلی (همان چیزی که «تمیز» می‌گویید)
- [ ] اگر سبک دومی هم دارید، یکی از آن
- [ ] اگر جایی استثنا دارید (مثلاً یک صحنه که خیلی خوشتان می‌آید)، همان را هم

**مدت:** ۳۰ تا ۶۰ ثانیه از هر کدام. فایل کامل لازم نیست.

**حجم:** زیر ۱۰۰ مگابایت. اگر فایل بزرگ است، برش بگیرید:

```bash
ffmpeg -ss 00:00:30 -i motion.mp4 -t 60 -c copy motion-sample.mp4
```

**دسته‌بندی:** اسم فایل‌ها را ساده بگذارید — `style-a.mp4`، `style-b.mp4`، `intro.mp4`. اگر لازم شد، یک فایل `media/samples/NOTES.md` با توضیح هر کدام بگذارید: «کدام را بیشتر دوست دارم»، «کدام برای چه کاربرد».

## فایل‌های اطلاعاتی — چه چیزی واقعاً کمک می‌کند

### اگر وقت کم دارید، این سه را بفرستید

1. **فونت واقعی** (`.ttf`) — فونت اشتباه، همه‌چیز را خراب می‌کند
2. **متن نریشن یا فایل `.srt`** — زمان‌بندی دقیق جمله‌ها
3. **فایل پروژه یا اسکرین‌شات از تایم‌لاین** — لایه‌ها و افکت‌ها را لو می‌دهد

### لیست کامل

- [ ] فونت (`.ttf` / `.otf`)
- [ ] متن نریشن (`.md` / `.txt` / `.docx`)
- [ ] زیرنویس (`.srt` / `.vtt` / `.ass`)
- [ ] فایل پروژه: `.aep` / `.prproj` / `.drp` / `.fig` / `.blend`
- [ ] اسکریپت کد: `scene.py` / `*.tsx` / `*.js`
- [ ] SVG آیکون‌ها یا `.ai`
- [ ] Lottie JSON
- [ ] اسکرین‌شات از نرم‌افزار (تایم‌لاین، لایه‌ها، تنظیمات افکت)
- [ ] راهنمای برند (PDF)
- [ ] promptها یا دستورهای تولید
- [ ] موسیقی / افکت صوتی

## سه هشدار

**۱) مخزن عمومی است.** هر چیزی که آپلود کنید برای همه دیده می‌شود. اگر فایل پروژه حاوی دارایی لایسنس‌دار است، فقط اسکرین‌شات بفرستید.

**۲) ویدیوهای دانشجوها را نفرستید.** فایل‌های `stu-*` کار اشخاص دیگر است. برای تحلیل ساختاری لازم نیست.

**۳) من نمی‌توانم به alvana.me وصل شوم.** GitHub تنها مسیر است. اگر فایلی را در جای دیگری (درایو، تلگرام) گذاشتید، به آن دسترسی ندارم.

## بعد از آپلود چه کار می‌کنم

۱. با `git clone` فایل‌ها را می‌آورم (تست شده، کار می‌کند)
۲. ویدیوها → تحلیل خودکار: شات، پالت، ضخامت خط، زیرنویس، ریتم + فریم کلیدی
۳. فایل‌های مرجع → استخراج فونت، رنگ، easing، ساختار لایه
۴. یک گزارش واحد: «این موشن‌ها چطور ساخته شده‌اند و چطور بازسازی کنیم»

بنویسید «گذاشتم» — بقیه‌اش با من.
