## ۰) خلاصه‌ی مدیریتی

**این ویدیوها با هوش مصنوعی ساخته نشده‌اند.** رندر کد است.

شاهد قطعی:

| شاهد | مقدار اندازه‌گیری‌شده | معنی |
|---|---|---|
| پیکسل‌های دقیقاً صفر | **۹۴٫۳۳٪** | مدل‌های ویدئویی تقریباً هرگز ۰ مطلق تولید نمی‌کنند |
| نشتی رنگ | **۰٫۰۰٪** (channel spread = 0.00) | ۱۰۰٪ خاکستری؛ هیچ رنگ تاکیدی نیست |
| ضخامت خط در 720p | **median ۳px** (p10=۲، p90=۴) | یکنواخت = استروک برداری، نه بافت AI |
| پرش بین فریم‌ها در ناحیه‌ی ثابت | **۰٫۰۸۷/۲۵۵** | پایدار = رندر قطعی |
| متادیتای کانتینر | `encoder=Lavf63.1.102` | خروجی FFmpeg با فریم‌های PNG |

**نتیجه‌ی عملی:** با ابزارهای **رایگان** می‌شود دقیقاً همین را ساخت. نه تقریباً — دقیقاً.

## ۲) پالت رنگ

هیچ رنگ تاکیدی وجود ندارد. کل ویدیو خاکستری است.

| نقش | مقدار | کاربرد |
|---|---|---|
| پس‌زمینه | `#000000` | کل کادر |
| خط اصلی | `#FFFFFF` | استروک اشکال، متن زیرنویس فعال |
| خاکستری ۷۰٪ | `#B4B4B4` (180,180,180) | خطوط ثانویه، تیک‌ها |
| خاکستری ۴۰٪ | `#6E6E6E` (110,110,110) | زیرنویس غیرفعال، خط هدر |

اگر برای پروژه‌ی الینا به رنگ تاکیدی نیاز داشتید، یک رنگ اضافه کنید — اما بدانید که **نمونه هیچ رنگی ندارد** و افزودنش ظاهر را عوض می‌کند.

## ۳) چیدمان (اندازه‌گیری‌شده در 720×1280)

```
y =   69– 88   نوار هدر: خط افقی + جعبه‌ی مورب با برچسب فصل (سمت راست)
y =  170–990   صحنه: تصویرسازی خطی، مرکز عملی ≈ 580
y = 1046–1073  زیرنویس: ارتفاع حرف ۲۸px، خط پایه 1067
حاشیه‌ها       ۴۷px چپ و ۴۳px راست
```

قاعده‌ی طلایی: حاشیه‌ی افقی ≈ ۴۵px (۶٫۳٪ عرض). هیچ عنصری از این خط بیرون نمی‌زند.

### هدر (سربرگ فصل)

یک نوار باریک بالای صفحه با ساختار ثابت:

- یک خط افقی نازک با خاکستری ۴۰٪ از `x=47` تا `x=673` در ارتفاع `y=96`
- در سمت **راست**، یک جعبه‌ی مورب (مثل برچسب پرونده): ضلع چپ با شیب ۴۵ درجه
- داخل جعبه: شماره/نام فصل به فارسی، و کلمه‌ی «پرونده» با خاکستری کم‌رنگ‌تر در کنارش
- این نوار در **۹۸٪ فریم‌ها** حاضر است و معمولاً تنها عنصر ثابت است

### زیرنویس

- یک خط، تمام‌عرض، وسط‌چین
- **کرااوکه کلمه‌به‌کلمه**: کلمه‌ی جاری سفید، بقیه خاکستری ۴۰٪
- بدون جعبه‌ی پس‌زمینه، بدون سایه
- اگر متن بلند شود، فونت کوچک می‌شود نه اینکه به خط دوم برود (اندازه‌گیری: max عرض ۸۶٪ کادر)

اندازه‌گیری دقیق کرااوکه روی ۸ فریم متوالی (۰٫۲ ثانیه فاصله):
پیکسل‌های روشن از ۱۷۴ به ۱۰۰۰ رسیدند در حالی که پیکسل‌های کم‌رنگ از ۱۹۹۴ به ۱۲۳۶ کاهش یافتند — یعنی **کلمه‌ها یکی‌یکی روشن می‌شوند** و متن از قبل کامل حاضر است.

## ۴) زبان تصویری

### الف) خط

- استروک **بدون پرکردن**. پر فقط برای مردمک و نقاط کوچک.
- ضخامت ۳px در 720p (≈ ۰٫۴۲٪ عرض). اگر 1080p می‌سازید: ۴٫۵px.
- گوشه‌های گرد، پایان‌های گرد (round cap/join).
- انیمیشن: **خط‌کشی** (draw-on). خط از یک سر شروع و به سر دیگر کشیده می‌شود، ۰٫۸ تا ۱٫۶ ثانیه.
- هیچ فید، هیچ اسلاید، هیچ zoom. حرکت فقط «رسم شدن» است.

### ب) آدمک

اندازه‌گیری روی ۷ آدمک ردیف پایین (هر یک ۵۷×۱۱۳px):

| نسبت | مقدار |
|---|---|
| عرض/ارتفاع کل | ۰٫۵۱ |
| سر | ۰–۲۷٪ ارتفاع، عرض ۲۵px |
| شانه | ۲۹٪ ارتفاع، عرض ۴۹px |
| کمر | ۶۰٪ ارتفاع |
| باسن | ۶۶٪ ارتفاع |
| پاها | ۶۶–۱۰۰٪ ارتفاع، دو ستون |
| فاصله‌ی آدمک‌ها | ۹۴px (center-to-center) |

سیلوئت یک گنبد شانه دارد، بازوها آویزان و کمی از بدن جدا، پاها دو ستون نازک با شکاف وسط.

> ⚠️ **محدودیت صادقانه:** بازسازی دستی این سیلوئت با ۵۷ پیکسل اطلاعات، به ~۸۵٪ شباهت می‌رسد. برای تطابق کامل و دقیق، مسیر SVG اصلی را از طراح بگیرید و با `SvgPath` بریزید. این در کد پیاده‌سازی شده است.

### ج) موتیف‌های تکرارشونده

۱. **چشم/ساعت** — دایره‌ی بزرگ + دایره‌ی داخلی + مردمک توپر با نقطه‌ی سفید (براق) + ۲۸ تیک ریز دور آن. پرتکرارترین عنصر ویدیو.
۲. **آدمک تنها** پایین کادر با یک خط عمودی که از شکل به بالا وصل می‌شود.
۳. **خوشه‌ی مفهومی** — یک شکل مرکزی، و ۱۲–۱۴ کلمه‌ی فارسی دور آن با خطوط نازک (مثل «آهنگ، گزارش، وعده، دستور، قانون، خبر...»).
۴. **وزنه‌ی ترازو** — کفه‌ها با آیتم‌های کوچک داخلشان، برای مقایسه.
۵. **ردیف آدمک‌ها** — ۷ نفر کنار هم، برای «همه‌ی ما».
۶. **جعبه/قفس** — برای مفاهیم محدودیت.

### د) کمپوزیسیون

- یک شکل **مرکزی** با ۱–۳ برچسب اطراف
- فضای خالی زیاد؛ عنصرها هیچ‌وقت کادر را پر نمی‌کنند
- تقارن عمودی حول `x=360`

## ۵) ریتم و زمان‌بندی

| پارامتر | مقدار |
|---|---|
| مدت نمونه | ۱۴۵ ثانیه |
| تیک‌های صوتی | ۶۸ بخش گفتار |
| میانگین طول جمله | ۱٫۸۹ ثانیه (میانه ۱٫۲۷) |
| گذار بین صحنه‌ها | **هیچ** — کات مستقیم، صفر ترنزیشن |

نکته‌ی مهم: آشکارساز صحنه در آستانه ۰٫۰۸ هم **صفر کات** پیدا کرد. دلیل فنی‌اش این است که ۹۷٫۷٪ فریم سیاه است، پس تغییر کلی کم است؛ اما ریتم واقعی از **تغییر محتوا در ناحیه‌ی صحنه** می‌آید. عملاً یعنی هر جمله ≈ یک شکل تازه، بدون افکت گذار.

## ۷) چطور همین را بسازیم — سه مسیر

### مسیر ۱: موتور آماده‌ی این ریپو (رایگان)

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install pillow numpy arabic-reshaper python-bidi imageio-ffmpeg
python scripts/demo_kino_scene.py
# → out/kino-demo/kino-demo.mp4
```

API:

```python
from motion.kino_engine import KinoScene, Person, Label, eye_clock, SvgPath

scene = KinoScene(duration=8.0, chapter="ترس اصلی")
scene.extend(eye_clock((360, 400), radius=92, at=0.0))
scene.add(Person(center=(360, 830), scale=1.0, at=1.6, dur=1.0))
scene.add(Label(pos=(500, 250), text="باورهایت", leader_to=(432, 350), at=3.0))
scene.set_captions([(0.4, 4.2, "یه ترس اصلی تون اینه که از ما باهوش‌تر")])
scene.render("out/my-scene/")
```

**مزیت:** صفر وابستگی به سرویس خارجی، رندر قطعی، فارسی درست (Vazirmatn + reshaper).
**محدودیت:** همه‌ی شکل‌ها را باید کد بزنید. برای ۵۰ صحنه صادقانه بگویم: زمان‌بر است.

### مسیر ۲: Manim Community (رایگان، قدرتمندتر)

مانیم همان کاری را می‌کند که این ویدیو کرده، ولی ابزارش کامل‌تر است.

```bash
pip install manim
manim -qh scene.py MyScene
```

برای فارسی: `Text("متن", font="Vazirmatn")` با `arabic_reshaper` روی متن.

**مزیت:** کتابخانه‌ی غنی از انیمیشن (Create، Transform، FadeIn)، ریاضی و نمودار آماده.
**محدودیت:** منحنی یادگیری تندتر؛ برای RTL باید reshaper را خودتان وصل کنید.

### مسیر ۳: Remotion (رایگان برای پروژه‌ی شخصی)

React/TypeScript، رندر با Chromium. اگر تیم شما وب‌کار است، این بهترین انتخاب است.

```bash
npx create-video@latest
```

**مزیت:** کل CSS/HTML در دسترس است؛ کتابخانه‌ی آیکون (Lucide) رایگان و بزرگ؛ ساختن ۵۰ صحنه سریع‌تر.
**محدودیت:** نیاز به Node؛ مصرف رم بالاتر.

### مسیر ۴: SVG آماده + انیمیشن (توصیه‌ی من برای سرعت)

آیکون‌های خطی رایگان از این‌ها بگیرید و با `SvgPath` یا مانیم انیمیت کنید:

- **Lucide** (lucide.dev) — MIT، ۱۵۰۰+ آیکون خطی، دقیقاً همین سبک
- **Phosphor Icons** — MIT، سبک خطی نازک
- **Iconoir** — MIT
- **Streamline Free** (محدود)

این آیکون‌ها همان زبان بصری نمونه را دارند: خط نازک، بدون پر، گوشه‌ی گرد.

## ۸) دستور پخت یک صحنه (چک‌لیست)

برای هر جمله‌ی نریشن:

1. **مفهوم را به یک شکل مرکزی ترجمه کن** — آدمک، چشم، جعبه، ترازو، خوشه
2. **۱ تا ۳ برچسب** اضافه کن، با خط راهنما از شکل به کلمه
3. **خط‌کشی ۰٫۸–۱٫۶ ثانیه** با ease-out
4. **زیرنویس کرااوکه** همان جمله، هم‌زمان با گفتار
5. **کات مستقیم** به صحنه‌ی بعد. بدون ترنزیشن.
6. مدت صحنه = مدت جمله (میانگین ۱٫۹ ثانیه، برای جمله‌های تعریف مهم تا ۵ ثانیه)
