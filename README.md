# روان‌شناسی مریم — Maryam Psychology OS

> **«اسمِ چیزی که حس می‌کنی.»**
> محتوای روان‌شناسی مبتنی بر شواهد، برای بزرگسالانی که بیرون خوب به‌نظر می‌رسند و درون خالی‌اند.

---

## این ریپو چیست؟

زیرساخت تولید و انتشار محتوای **مریم (روان‌شناس بالینی)** و جهان تصویری **الینا و الی**.
هدف: نام‌گذاری دقیق دردهای نامرئی، توضیح علمی مکانیسم‌ها، و ساختن مسیر اخلاقی از «دیده‌شدن» به «کمک گرفتن».

> ⚠️ **تاریخچه:** این ریپو در ابتدا برای یک اینفلوئنسر فشن (Petite Quiet Luxury) ساخته شده بود.
> در پاس `cleanup/remove-fashion-content` تمام محتوای فشن، افیلیت، تصاویر آواتار فشن و ایجنت‌های مربوطه حذف شد.
> مستندات تاریخی در `docs/archive/` نگه داشته شده‌اند.

## آناتومی هر ویدیو

```
۰–۲ ثانیه    هوک: نام‌گذاری درد، بدون مقدمه، بدون لوگو
۲–۸ ثانیه    رفریم: «تو مشکل نیستی؛ این اسم دارد»
۸–۲۰ ثانیه   مکانیسم: علم، به زبان ساده
۲۰–۳۰ ثانیه  قدم صفر: یک اقدام کوچک و قابل اجرا
۳۰–۳۵ ثانیه  پل اخلاقی: «اگر این چند هفته با تو مانده، با متخصص صحبت کن»
```

قواعد سخت:
- هر ۲ تا ۳ ثانیه یک تغییر بصری
- پایان به آغاز وصل شود (loop = watch time)
- زیرنویس فارسی همیشه روشن
- یک CTA: ارسال به یک نفر خاص

## معماری سیستم

```
GitHub Actions (سرور)
│
├── TrendHunter            ← ترندهای روان‌شناسی (Reddit: psychology, CPTSD, burnout…)
├── ContentCreator         ← کپشن فارسی/انگلیسی بر اساس ستون‌ها
├── Carousel Studio        ← رندر کاروسل با تم برند
├── Editing Pipeline       ← ffmpeg، زیرنویس، صدا، تدوین
├── Safety Guardian        ← گیت ایمنی محتوا (L1–L4)
├── Publisher              ← Instagram / YouTube Shorts
└── Scheduler              ← صف و زمان‌بندی
```
