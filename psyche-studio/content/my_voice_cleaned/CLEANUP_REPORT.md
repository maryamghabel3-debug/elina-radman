# Project 001 - Automated Audio Cleanup Report

Generated by `engine/audio_clean.py`. Raw recordings in `content/my_voice/` were not modified. All measurements are objective (ffmpeg ebur128/astats and sample-level RMS analysis); no subjective listening evaluation was performed.

## Pipeline

1. Continuous f32le decode, 1152-sample (~26.1 ms) RMS windows; gate = measured noise floor + 6 dB; lead/trail room tone trimmed with 130 ms padding.
2. Click treatment only at the pre-flagged windows: a 10 ms peak-anchored de-click envelope - asymmetric 0->0.35->1 fade for recording-start flags, symmetric 1->0.35->1 dip for the interior flag. Never applied to the whole file.
3. Internal sub-gate runs > 0.9 s compressed to 0.35 s, spliced at zero crossings. A run is cut only when its median RMS sits within 3 dB of the room-tone floor, no window exceeds -30 dB RMS, and voiced coverage stays >= 99 %. The Phase-3 coarse scan predicted only scene 7 would qualify; sample-level analysis found additional room-tone-only pauses in scenes 1/4/5 (evidence per run below), so those were compressed as well - no speech-level window was removed.
4. `highpass=80 -> afftdn=nr=10:nf=-40 -> acompressor(th=-20dB, 2:1, 10/120ms) -> two-pass loudnorm(I=-16, TP target -2.0 for MP3 headroom, LRA=11) -> alimiter(0.95)`; mono 44.1 kHz 128 kbps MP3. The finished file must still pass the true-peak gate of -1.5 dBTP; the -2.0 target absorbs lossy-encode overshoot.
