# voice_bashe — temporary synthetic narration

> ⚠️ **PUBLIC WARNING — این یک مخزن عمومی است. This directory lives in a PUBLIC repository.**
> Everything pushed here is visible to anyone on the internet and may be indexed by search engines.

## What this folder is for

- **Temporary synthetic narration only** — machine-generated speech such as
  Microsoft **Edge TTS**, Piper, or other text-to-speech output used while
  building and reviewing motion-graphics videos.
- Each scene's audio and its subtitle file must be uploaded **together**,
  using matching names:

  ```
  scene_01.mp3
  scene_01.srt
  scene_02.mp3
  scene_02.srt
  ```

## What must NEVER be uploaded here

- ❌ Human-recorded voice (your own voice or anyone else's)
- ❌ Private voice samples, auditions, or scratch recordings
- ❌ Personal data, private conversations, or confidential material
- ❌ Any recording made without the speaker's informed consent

Human voice belongs in the separate **private** repository
(`psyche-private-assets`), never in this public repository. If a file was
uploaded here by mistake, delete it and remember that Git history may still
contain it — contact the repository maintainer before assuming it is gone.

## فارسی — خلاصه قوانین

- این پوشه داخل مخزن **عمومی** است؛ هر فایلی که اینجا آپلود کنید روی اینترنت
  قابل‌مشاهده است.
- اینجا فقط برای صدای **موقت مصنوعی** (مثل Edge TTS) است.
- هرگز صدای ضبط‌شده‌ی انسانی، نمونه صدا، اطلاعات شخصی یا صدای فردی بدون رضایت
  او را اینجا آپلود نکنید.
- برای هر صحنه، فایل `.mp3` و فایل متناظر `.srt` را با نام یکسان و کنار هم
  بگذارید (مثال بالا).
- صدای انسانی فقط در مخزن خصوصی `psyche-private-assets` نگهداری می‌شود.
