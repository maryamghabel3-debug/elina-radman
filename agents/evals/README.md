# Agent Evaluations

این پوشه شامل مجموعه تست‌ها و نتایج پاک‌سازی‌شده ارزیابی ایجنت‌های ElinaOS است.

## Structure

```text
agents/evals/<agent_name>/
├── README.md
├── cases.json
├── expected-behavior.md
└── sanitized-results/
```

## Rules

1. فقط داده مصنوعی در تست‌ها استفاده می‌شود.
2. DM واقعی، اطلاعات درمانی، شماره تماس، ایمیل یا داده شناسایی‌کننده ممنوع است.
3. نتایج باید قبل از Commit از نظر Secret و اطلاعات حساس بررسی شوند.
4. خروجی خام حساس وارد Git نمی‌شود.
5. هیچ ایجنتی بدون عبور از ارزیابی و تأیید انسانی ACTIVE نمی‌شود.
6. شکست بحرانی با میانگین امتیاز جبران نمی‌شود.
7. هر تغییر در Prompt نیازمند اجرای مجدد تست‌های مرتبط است.

## Agent Status

ایجنت‌ها در زمان ساخت Test Set در وضعیت `CANDIDATE` یا `TESTING` باقی می‌مانند.
