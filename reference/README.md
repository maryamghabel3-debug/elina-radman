# فایل‌های مرجع — هر چیزی که «اطلاعات» می‌دهد

این پوشه برای فایل‌های غیرویدیویی است که به ما می‌گوید موشن‌ها **چطور** ساخته شده‌اند.
هرچه اینجا بگذارید، مستقیم در تحلیل استفاده می‌شود.

## چه چیزی مفید است (به ترتیب ارزش)

### طلا 🥇 — این‌ها را اگر دارید حتماً بفرستید

| فایل | چه می‌گوید | مثال نام |
|---|---|---|
| **فایل پروژه‌ی After Effects** | تک‌تک لایه‌ها، افکت‌ها، بیان‌ها، زمان‌بندی | `motion.aep` |
| **فایل Figma** (لینک یا export) | لایه‌بندی، استایل‌ها، رنگ‌ها، تایپوگرافی | `design.fig` |
| **فایل پروژه‌ی Premiere / DaVinci** | تایم‌لاین، ترنزیشن، تنظیم رنگ | `.prproj` / `.drp` |
| **اسکریپت کد** (Manim / Remotion / Python) | خودِ منطق ساخت | `scene.py`, `*.tsx` |
| **SVG یا AI آیکون‌ها** | دقیق‌ترین منبع برای بازسازی شکل‌ها | `icons.svg` |
| **فایل Lottie / JSON انیمیشن** | انیمیشن برداری با کی‌فریم | `anim.json` |

### خیلی مفید 🥈

| فایل | چه می‌گوید |
|---|---|
| **متن نریشن** (`script.md`, `.txt`, `.docx`) | محتوای دقیق + زمان‌بندی جمله‌ها |
| **فایل زیرنویس** (`.srt`, `.vtt`, `.ass`) | زمان دقیق هر جمله — برای کرااوکه حیاتی است |
| **فونت‌ها** (`.ttf`, `.otf`) | فونت واقعی، نه حدس من |
| **راهنمای برند** (PDF) | رنگ، تایپوگرافی، لحن |
| **promptها یا دستورهای تولید** | اگر با AI ساخته شده، این‌ها کلید است |
| **صفحه‌بندی / storyboard** | برنامه‌ی صحنه‌ها |

### مفید 🥉

| فایل | چه می‌گوید |
|---|---|
| اسکرین‌شات از نرم‌افزار | مثلاً عکس از تایم‌لاین AE یا لایه‌های Figma |
| فایل صوتی نریشن جدا | تا هم‌زمانی را دقیق بسنجیم |
| موسیقی / افکت صوتی استفاده‌شده | پالت صوتی برند |
| فایل خروجی `.json` از ابزارهای AI | متادیتای تولید |

## چه چیزی مفید نیست

- فایل‌های فشرده با رمز
- فایل نصب نرم‌افزار
- نسخه‌ی خروجی نهایی (همان mp4) — آن را در `media/samples/` بگذارید، نه اینجا
- هر فایلی که خودتان مطمئن نیستید مالک آن هستید

## چطور بفرستید — سه راه

### راه ۱: در همین چت (ساده‌ترین برای فایل‌های سبک)

فایل را در همین گفتگو **ضمیمه** کنید. تا حدود ۵ مگابایت. برای متن، فونت، SRT، JSON، اسکرین‌شات و SVG بهترین راه است.

### راه ۲: در گیت‌هاب (برای فایل‌های سنگین‌تر)

```
https://github.com/maryamghabel3-debug/elina-radman/upload/arena/dddfb643-elina-radman/reference
```

پوشه‌ی درست را انتخاب کنید: `docs`، `screenshots`، `presets` یا `projects`.

> ⚠️ این مخزن **عمومی** است. فایل پروژه‌ی `aep` ممکن است شامل دارایی‌های دارای لایسنس باشد. اگر نگرانید، فقط اسکرین‌شات بفرستید.

### راه ۳: فقط بنویسید کدام‌ها را دارید

اگر فایل سنگین است یا فرستادنش سخت است، فقط بگویید «فایل aep دارم» تا بگویم دقیقاً چه بخشی از آن لازم است.

## فونت و متن — اولویت اول

اگر فقط **دو چیز** بتوانید بفرستید، این دو را بفرستید:

1. **فایل فونت** استفاده‌شده در موشن‌ها (`.ttf`)
2. **متن نریشن یا فایل `.srt`**

این دو، بیشترین تفاوت را در دقت بازسازی می‌سازند. فونت اشتباه = خروجی اشتباه، حتی اگر همه‌چیز دیگر درست باشد.
