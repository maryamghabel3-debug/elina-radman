# Ellie — Reference-Image Usage Policy

> **Character ID:** `ellie`
> **Scope:** This policy governs how **Ellie / Elli / الی** reference images are used
> in production. It is about **Ellie** only and does not describe Elina / الینا.
>
> Companion document: [ellie_visual_lock.md](ellie_visual_lock.md) (owner-confirmed
> visual specification).

## The three reference roles (not interchangeable)

| Role | Purpose |
| --- | --- |
| **CHARACTER REFERENCE** | Preserves Ellie's **identity**: proportions, face design, linework. |
| **ENVIRONMENT REFERENCE** | Preserves the **set**: materials, layout, and lighting language. |
| **START FRAME** | A specific image deliberately selected as the **opening frame of a clip**. |

These roles are **not interchangeable**. An image used as a character reference is not
a start frame; an environment reference is not a character reference.

## When an image is supplied as a CHARACTER REFERENCE

- **Preserve identity** — Ellie's proportions, face design, and linework — **not** its
  original pose or camera angle.
- **Do not** automatically reproduce its off-white background.
- **Do not** automatically animate the reference card itself.
- **Create the new shot** specified by the production prompt, using the reference for
  identity only.

## Image-to-video tools (first-frame-only)

When a tool only supports **image-to-video from a first frame**:

1. First **create and approve a new shot-specific image** using the character reference
   (identity only — new pose, framing, and setting per the production prompt).
2. Then **animate that NEW image**.

**Do not** claim that wording alone changes a start-frame input into an
identity-reference input. A first-frame input is a start frame; identity must be
supplied through the newly created, approved shot-specific image.

## Identity vs. episode art direction

- A cinematic, realistic environment may surround the flat-drawn Ellie, but the
  environment is **not** part of Ellie's body design.
- Do **not** impose a universal ban on environmental shadows or mirror reflections —
  later story rooms require them. Ellie's body stays flat white while the scene may use
  intentional shadows or reflections.
- "No built-in accessories" does **not** prohibit story props (e.g., holding the pocket
  watch after the Waiting room).

## House story — «Elli بزرگ» و «Elli کوچک»

«Elli بزرگ» (big Elli) and «Elli کوچک» (little Elli) in the house story are
**narrative versions of Ellie** — narrative scale/role variants, not separate
characters. **Do not silently replace the larger Ellie with Elina.**

## Superseded misinterpretations (Ellie only)

Realistic 6–7-year-old girl · dark hair · gray/blue realistic eyes · pale human skin ·
cream dress · realistic fingers or anatomical detail — all **SUPERSEDED** for Ellie.
Do not apply these to Elina. See [ellie_visual_lock.md](ellie_visual_lock.md).

## حریم خصوصی (Privacy)

Do not commit original reference images, character sheets, multi-angle/expression
sheets, or Golden Reference Images to this public repository. This folder holds public
documentation, non-sensitive metadata, and safe pointers only. No credentials, signed
URLs, or sensitive asset locations are recorded here. See
[README-UPLOAD-HERE.md](../README-UPLOAD-HERE.md).
