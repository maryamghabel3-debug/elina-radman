# اینجا ویدیوهای نمونه را بگذارید

## قبل از آپلود

- فایل‌ها را همین‌جا (در `media/samples/`) بریزید. زیرپوشه هم مشکلی ندارد.
- نام‌گذاری پیشنهادی: `lesson-04.mp4`، `stu-11.mp4`، `nfp-16.mp4` — تا در گزارش معلوم باشد کدام چیست.
- فرمت‌های پشتیبانی‌شده: `.mp4` `.mov` `.webm` `.mkv` `.m4v` `.avi`

## حجم — مهم

| حجم فایل | روش |
|---|---|
| زیر ۲۵ مگابایت | آپلود مستقیم در GitHub (کشیدن-و-رها) |
| ۲۵ تا ۱۰۰ مگابایت | همان آپلود مستقیم؛ GitHub تا ۱۰۰MB اجازه می‌دهد و این workflow ffmpeg نصب‌شده دارد |
| بیش از ۱۰۰ مگابایت | Git LFS، یا فقط ۳۰ ثانیه‌ی اول هر ویدیو را بفرستید |

**برای تحلیل، ۳۰ تا ۶۰ ثانیه از هر ویدیو کافی است.** لازم نیست فایل کامل ۵۰۰ مگابایتی را آپلود کنید. با ffmpeg خودتان یک برش بگیرید:

```bash
ffmpeg -ss 00:00:30 -i lesson-04.mp4 -t 60 -c copy lesson-04-sample.mp4
```

## بعد از آپلود چه می‌شود

۱. این workflow خودکار اجرا می‌شود (`.github/workflows/analyze-samples.yml`)
۲. برای هر فایل: تعداد شات، مدت هر شات، پالت، ضخامت خط، ریتم گفتار
۳. تست «رندر کد یا ویدیوی AI» روی هر شات
۴. یک فریم کلیدی از هر شات در `analysis/keyframes/`
۵. گزارش کامل در Artifacts

## هشدار حقوقی

فقط محتوایی را بگذارید که مالک آن هستید یا اجازه‌ی استفاده دارید.
کار دانشجوها (stu-*) مال دانشجوهاست — اگر رضایت‌نامه ندارید، آپلود نکنید.
برای تحلیل ساختاری، همین که **یک** ویدیوی نمونه از هر سبک را بفرستید کافی است.
